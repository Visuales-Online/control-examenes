# Control de exámenes médicos ocupacionales

Herramienta web para llevar el control de los exámenes médicos ocupacionales (ingreso, periódico, seguimiento, retiro) por sede.

- Lee los certificados en PDF **en el computador de quien la usa**: los PDF no se suben a ningún servidor.
- Cruza los exámenes con la base de personal activo (Excel) y calcula el próximo examen según la frecuencia de cada colaborador.
- Los datos se guardan en el navegador y, si se vincula, en un archivo de datos en una carpeta compartida de la empresa.

**Este repositorio no contiene datos de personas.** No subas aquí PDF, bases de personal ni archivos `datos_examenes_medicos.json`.
